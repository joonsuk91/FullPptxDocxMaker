bible_json_corrected.zip 설명

- bible_ko.json: 한글 오타/옛 맞춤법으로 보이는 부분을 보정한 수정본입니다.
- bible_en.json: 사용자가 올린 원본 영어 JSON을 그대로 보존한 파일입니다.
- bible_ko_correction_log.csv: 수정된 구절 목록입니다.
- bible_ko_correction_log.json: 수정 내역 JSON 로그입니다.

- 책 수: 66

수정 원칙:
1. 성경 구절 번호/장/절 구조는 바꾸지 않았습니다.
2. 영어 성경 데이터는 수정하지 않았습니다.
3. 한글 본문은 고확률 패턴만 수정했습니다.
   - 할찌니라 -> 할지니라
   - 있을찐대 -> 있을진대
   - 죽을찌언정 -> 죽을지언정
   - 할쌔 -> 할새
   - 일찌기 -> 일찍이
   - 여호화/속희/흘들 등 명확한 오타가 있을 경우 교정
4. 살찌다, 찌르다, 찌끼, 어찌 같은 실제 단어는 바꾸지 않았습니다.
5. 본문 전체를 개역개정으로 바꾼 것이 아니라, 기존 JSON의 문체를 최대한 유지하면서 오타처럼 보이는 표기를 정리했습니다.
